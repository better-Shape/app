AnimGif NSIS plug-in
====================

The binary in this folder is the Unicode x86 build of AnimGif, the NSIS
plug-in that animates a GIF on an installer page. It is redistributed
unmodified. The upstream repository publishes no top-level LICENSE file, so
the terms are the per-file notices reproduced verbatim below. Both grant use,
copy, modification, distribution and sale for any purpose without fee, which
covers shipping the DLL inside this installer.

Upstream source: https://github.com/nsis-community/plugin-animgif
Source inspected at commit e3b6084f69981eaf999931f925b0a1cf5a0d78af.
The mirror is built by the nsis-dev release action from
Contrib/AnimGif/animgif.cpp, Contrib/AnimGif/winimage.cpp and
Contrib/AnimGif/winimage.h.

Binary source: https://github.com/nsis-dev/plugin-corpus
Path: tree/Plugins/x86-unicode/animgif.dll
SHA-256: a1fa2e0191f986824f5fc0ef62aee8b4b25695cc56d4b00fecdc1c92f8ea237f

The mirror does not tag the build, so verify a replacement by rebuilding
from the upstream source with nsis-dev/release-package (x86-unicode
variant) and diffing the export table (play, stop) and the SHA-256 above.
