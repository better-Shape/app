Every message uses a model. You pick it from the model menu in chat.

## Add a provider

Open **Settings → Providers** and paste an API key for the provider you use:

| Provider | Key from | Notes |
| --- | --- | --- |
| OpenAI | platform.openai.com | GPT models, embeddings, images, speech. |
| Anthropic | console.anthropic.com | Claude models. |
| Google | aistudio.google.com | Gemini models. |
| OpenRouter | openrouter.ai | One key for many providers. |
| xAI, DeepSeek, Groq, Mistral | their dashboards | OpenAI-compatible. |
| Custom | your own endpoint | Any OpenAI-compatible base URL, including a local runtime. |

Chat works as soon as one provider is enabled with a key. Without one, BetterShape says so instead of failing mid-turn.

## Pick a model

The model menu lists the models your key can reach, plus anything extra you add by hand. The default is **Auto**, which uses your first configured provider unless you set a different default in **Settings → Providers**.

## Embeddings and search

Codebase search uses an OpenAI-compatible `/embeddings` endpoint. Point **Embedding model** at one your provider offers, or turn embeddings off; keyword search and the file index still work.

## Media

Image, speech, and caption tools need an OpenAI-wire provider. They use the same key as chat.

## Cost

Your provider bills you directly. BetterShape shows the tokens spent on the last turn in the composer ring, not a credit balance.
