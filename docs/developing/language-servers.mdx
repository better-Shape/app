## Overview

The BetterShape editor is CodeMirror 6. Completions and highlighting come from language packs for the file type. There is no LSP client, no Monaco workers, and no `features/editor/lsp/` process.

Workspace trust still gates whether the **agent** can edit files and run commands in a folder. It does not start language servers.
