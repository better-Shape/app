You need Node.js 22.13+ (or 24+), and a current Rust toolchain for [Tauri 2](https://v2.tauri.app/start/prerequisites/).

This is how you run a local build. It is not how you use BetterShape day to day. For that, install the app from [GitHub releases](https://github.com/Owie6789/BetterShape/releases).

See [Platform build status](./platform-support) for the configured installer targets and their verification requirements. A successful source build is not an install smoke test.

## Install dependencies

```bash
npm install
```

Run this at the repo root the README names for the desktop app. If the monorepo has more than one package, follow that README, not this page, for the exact folder.

## Run the app

```bash
npm run tauri:dev
```

That opens the desktop app against your local build. The first run compiles Rust and takes longer.

On Windows, every build (including release) writes a memory sample every 10 seconds to `%LOCALAPPDATA%\bettershape\ram-debug.log`: this process, its WebView2 children, handle and GDI counts. It is capped at 8 MB. Set `BETTERSHAPE_RAM_DEBUG=0` to turn it off. If BetterShape eats RAM, that file is what to send.

## Tests

```bash
npm run test
```

`npm run test:all` also runs the Rust tests. Run the suite that matches the files you touched.

If your machine cannot reach `sh.rustup.rs`, `crates.io` or the Playwright browser CDN, the Rust
tests and the browser suite still run. Fetch the orphan branch `vendor/sandbox-toolchain` and follow
its `FETCH.md`, then read `engineering/rust-toolchain.md` for the flags the cargo gates need. That
path was verified end to end on 2026-10-16.

## Sending the change

Commit on a branch and open a pull request against `main`. Keep the diff focused. See [Overview](/docs/developing/overview).
