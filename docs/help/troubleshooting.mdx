## The app will not open

It needs Windows 10 or 11, 64-bit. Download the installer again from [useshape.org/download](https://useshape.org/download) and run it.

If it opens and closes immediately, run it once more after a reboot. If it still fails, send the version you tried to install.

## Chat says no provider is configured

Open **Settings → Providers** and add an API key. BetterShape calls the provider directly with that key; there is no account to sign in to. If a key is set and send still fails, the provider returned the error — the status line under the message names the provider and the HTTP status.

## A model does not appear in the menu

The menu lists the models offered by presets, plus anything in **Extra models** on the provider card. Add the id by hand if your provider serves a model we do not list.

## The preview cannot reach localhost

Start your app first, then open that URL in the [browser](/docs/agent/browser).

`localhost` has to be the same machine. A URL on another device will not load in BetterShape’s preview.

## GitHub data is missing

[Sign in with GitHub](/docs/git/github) and open a folder whose remote is on github.com. A fork or an org the GitHub account cannot see will look empty.

## MCP tools do not appear

Save `mcp.json`, restart BetterShape, and open the folder again. The `command` has to exist on `PATH` for the app, not only for a terminal you already opened. See [MCP](/docs/customize/mcp).

## An update did not apply

Use **Help → Check for Updates**. If it still reports the old version, install over it from [download](/download).
