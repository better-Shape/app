BetterShape is a desktop app for Windows 10 or 11, 64-bit.

There is no browser-only editor. You download the app, then open a folder on disk.

## Download

1. Get the installer from [GitHub releases](https://github.com/Owie6789/BetterShape/releases).
2. Run it.
3. If Windows SmartScreen appears, choose **More info**, then **Run anyway**.
4. Open BetterShape from the Start menu.

If the installer will not run, you are on 32-bit Windows, or the download was cut short. Download it again.

## Add a model provider after install

There is no account to create and nothing to sign in to. BetterShape has no server of its own,
so chat runs once you supply a model key yourself.

1. Open **Settings**, then **Providers**.
2. Add a key for OpenAI, Anthropic, or Google — or any OpenAI-compatible endpoint.
3. Pick a default model under **Settings**, then **AI**.

Until a usable provider is configured, the composer stays disabled and says so. Everything else —
opening files, editing, git, terminal — works without one.

## Updates

This build has no update feed. **Help → Check for Updates** contacts no server.

If you need a newer version, download a fresh installer from [GitHub releases](https://github.com/Owie6789/BetterShape/releases) and run it over the existing install.

## Uninstall

Uninstall from Windows Settings like any other desktop app. Your project files on disk are not deleted. Local BetterShape data for the app may remain under your user folder.
