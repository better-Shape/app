## Can I work offline?

Editing files, search, and the terminal work without a connection. Chat and Git push/pull need one.

## Is there a free tier or a credit balance?

No. BetterShape has no account, no plan, and no credits. You pay your model provider directly for what you use.

## Does BetterShape upload my project?

Not by default. Chat sends the files and context you include in a turn, plus what the agent reads to do the task. Local editing does not require chat.

## Can I use my own model key?

That is the only way chat works. Add a key in **Settings → Providers** — OpenAI, Anthropic, Google, OpenRouter, or any OpenAI-compatible endpoint. Nothing is proxied through a server we run.

## What OS is supported?

Windows 10 or 11, 64-bit. See [Install](/docs/help/install).

## Is there anything to sign in to?

No. There is no BetterShape account. The only credentials in the app are the provider keys you add and the Git host login you use for push and pull.
