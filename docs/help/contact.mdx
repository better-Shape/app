Product questions go to [contact](/contact/sales). Include:

- The version from **Help → About**.
- What you tried, and what happened instead.

Do not send API keys, provider tokens, or a dump of `.env` files.

## Billing

There is nothing to bill here: BetterShape has no account and no subscription. Model usage is billed by the provider whose key you added.

## Security

Security issues go through [SECURITY.md](https://github.com/Owie6789/BetterShape/blob/main/SECURITY.md) on GitHub. Do not file those as a normal product question.

## Status

If a provider's API is down, check that provider's status page before you write in.
