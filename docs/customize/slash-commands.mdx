A slash command is a name plus a prompt you reuse. Type `/` in chat to pick one.

Use this for work you do the same way every time: writing a commit message, checking a PR, generating tests in a fixed shape.

## Add one

1. Open **Settings → Agents → Workflows**.
2. Give it a short name. That name is what you type after `/`.
3. Write the prompt you want Shape to follow. Be specific about the output: a commit message, a list of risks, a test file, and so on.
4. Save it.

Keep the prompt as the instructions, not as a one-off about the current branch. The current project still comes from the open folder and the thread.

## Run one

Type `/` in the composer and choose the command. You can add extra text after it, such as `/commit focus on the billing page`.

A trigger phrase in a normal message can run it too, if you set one on the command.

## What to put in the prompt

Write it like you would brief a person who has never seen this repo:

- What to look at (`@` files, or “the diff in source control”).
- What to produce.
- What to avoid (“do not change snapshots”).

Bad commands are one word. “Review” with no standard is not a command. The [Review](/docs/agent/review) mode already exists.

## Edit or delete

Open **Settings → Agents → Workflows** again. Change the prompt, or delete the command. Existing threads do not change.

Skills (reusable instructions the agent can load) live under **Settings → Agents → Skills**. They are separate from slash commands.

## Built-in commands

Shape ships a few commands that are not prompts. They run locally and never reach the model.

| Command | What it does |
| --- | --- |
| `/compact [focus]` | Summarize the earlier part of the thread and keep going. |

### /compact

Long threads eventually fill the model's context window. `/compact` folds the older turns into one summary, keeps the newest turns verbatim, and continues in the same thread.

Use it when:

- The thread is long and Shape starts forgetting things you said earlier.
- You finished a stage of work and want to start the next one without the old noise.
- A request failed because the context was too long.

Add a focus to steer the summary: `/compact keep the migration plan and the API shapes`. Without a focus, Shape uses your standing compaction instructions from **Settings → Agents → Instructions → Compaction**.

Shape also compacts on its own when a thread gets close to the window limit, so you rarely have to run this. The summary is the record of what was folded — everything before it stays in the transcript for you to scroll, and older turns are not deleted from the thread.

See [Context and compaction](/docs/agent/context) for what is kept and what is dropped.
